# GreenLeaf Organics

Static marketing website for **GreenLeaf Organics** — a certified organic food shop in Georgetown, Guyana.

Built for **F3T2 12 — Computing: Authoring a Website** (SCQF Level 6).
Student: Kareem Nurw Jason Schultz · ID 252IFCBR0596

## Stack
- HTML5 (5 pages: Home, Products, About, Gallery, Contact)
- Tailwind CSS (Play CDN) + custom `css/style.css`
- Google Fonts (Inter)
- Unsplash open-licence imagery
- Vanilla JavaScript (scroll-reveal, product filter tabs, form validation)

## Live site
Hosted on GitHub Pages: https://kareemschultz.github.io/greenleaf-organics/

## Run locally
Open `index.html` in any modern browser — no build step required.
